# Bundled plugin ports

The Hello Dolly 1.7.2 behavior and lyric data are ported from the user-supplied `wp-content/plugins/hello.php`, by Matt Mullenweg. Song: **Hello, Dolly!**, by Jerry Herman. The original author and song attribution are preserved in the admin display. The reference plugin is distributed with WordPress under GPL-2.0-or-later; the underlying song retains its original copyright.

Akismet Anti-spam 5.7.2 behavior/API integration is ported from the user-supplied `wp-content/plugins/akismet/`. Copyright 2005–2025 Automattic, Inc.; GPL version 2 or later. This program is distributed without any warranty, including the implied warranties of merchantability or fitness for a particular purpose. The repository root `LICENSE` contains GPL version 2.

These are Node/React ports. No PHP source is executed. Akismet's name identifies the upstream plugin and remote service; an operator supplies their own service key and explicitly enables comment processing. API documentation: https://akismet.com/developers/detailed-docs/ . The service and its plans remain subject to its operator's terms.
