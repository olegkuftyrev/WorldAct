# Public documents

`PublicDocumentView` is the shared Node-safe React presentation. It renders the existing Classic JSX or a source template as an opaque HTML island. The server model contains authorized public presentation fields and a minimal viewer; it never substitutes a full administrative User. The view imports no browser editor, DOM template parser, session resource hook or waveform runtime. CSS and browser enhancements belong to the browser entry.

Production HTML contains the complete request-time presentation and one inert, escaped model. The fixed head lifecycle script gates the entire composited root before it can paint, and inerts the root when the parser creates it. Every JavaScript-enabled document, including an anonymous one, waits for one fresh owned document validation before exposure. This deliberately delays anonymous first paint by that validation; it does not render a fake Loading tree. A matching model hydrates the existing server nodes; a changed model replaces the gated tree before exposure. The captured model is consumed once and its script is removed. There is no document-body storage or reusable bootstrap cache. With JavaScript genuinely disabled, the authorized request-time HTML remains visible and native forms work normally.

The controller assigns a distinct owner to each route/account generation, including an A→B→A return and same-account relogin. Departed requests and mutation callbacks cannot acquire a later owner. Pagehide synchronously gates and retires the current public root; persisted pageshow obtains a fresh model before exposure. Input, Reply and a newer submission retire a pending post-success model refresh, preserving the newer draft and its live feedback. Comment submission busy state ends with the actual POST rather than waiting for that background refresh.

React owns ordinary Classic controls and the toolbar. Delegated handlers run only in explicitly marked opaque HTML islands: source templates, Classic custom template slots and post body HTML. The two event owners do not compete for a form or link. Existing native actions, methods, names, hidden post/eligible parent IDs and paging URLs remain usable without JavaScript. Browser-only enhancers clean up their timers, listeners, disclosures and players on departure and StrictMode replay; waveform code is loaded after hydration.

A module error or delayed boot displays a fixed error and reload control outside the gated root. A failed model validation replaces the old tree with a current safe error/retry view. Neither fallback reveals old HTML. Head adoption removes only tagged public/compiler-default metadata, then owns one current title, metadata and icon set. No privacy claim revokes bytes already delivered to a genuinely JavaScript-disabled authorized request, or treats no-store as proof that browser history is safe.

Author and independent acceptance evidence is required before release; implementation of these paths alone is not evidence of full WordPress parity.
