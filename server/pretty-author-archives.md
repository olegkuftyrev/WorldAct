# Pretty author archives

WorldAct generates pretty author links from the current permalink structure's static front, `author/`, and the actual stored `users.nicename`. For `/journal/%year%/%postname%/` this is `/journal/author/nicename/`; partial fronts such as `/blog-%postname%` produce `/blog-author/nicename`. The structure's trailing slash style is retained. Plain links remain `/?author=ID`.

The shared helper does not derive identity from display name or username. The resolver performs the supplied WordPress default query-context ASCII normalization before looking up the persisted nicename: lowercase, period to hyphen, punctuation/entity/tag removal, whitespace to hyphen, collapsed hyphens. Malformed escapes, encoded segment separators and controls are bounded errors. Unicode/escaped-octet outputs outside the current stored ASCII domain are reserved404 rather than accent-folded into a different account.

An assigned doubled-hyphen slug is emitted unchanged. Source's later query normalization may collapse it, producing404 or another separately existing public account. This deliberately preserves the supplied source's inferred suffix-after-sanitize quirk; it is not a claim that every valid assigned slug reaches its own account through pretty paths. No stored identity is renamed. No PHP was executed.

Framework, explicit Plain identity and explicit legacy post/page routes keep their established priority. Existing configured taxonomy namespaces precede the new author namespace. A recognized author namespace precedes ordinary post/page/body continuation fallback; an unknown author cannot become a colliding page or another content identity.

The new source `/page/N/` author archive page is separate from content pages, `query-N-page`, and comment pages. Conflicting, duplicate or nested recognized author/page values are rejected. Pretty empty/excessive paged archives404; an existing account's first page200 may expose ordinary display name, actual ID, persisted slug and canonical only. Private profile fields and unpublished/protected bodies do not become author metadata. Existing numeric aliases retain their previous empty/excessive200 policy.

Server source templates use author-nicename, author-ID, author, archive, index hierarchy. Classic uses the same selected author template in its index slot; default Classic layout remains the fallback. Legacy client/site/template APIs consume the actual resolved archive ID/page, and send the visible pretty `requestPath` so the server can validate path identity. Ordinary non-author paths retain their existing content/archive counter semantics.

One pending document/site/template acquisition pins the first actual resolved ID plus persisted slug, including whole-read retries. Later retirement, rename or replacement yields a bounded404/409; it never silently substitutes a recreated account in that pending response. The server-only author observation set validates all earlier identities after rendering and before the existing final post/publication/password-token policy statement. No author expression runs after that grant fence. This bounds author identity to its final statement and does not claim atomic global settings/profile/term state. Caller-supplied writable and read-only repeatable-read snapshots keep their visibility semantics; no new broad read transaction or global-pool escape is introduced.

Post author-name/post-author links, non-comment avatars, author breadcrumbs, registered Latest Comments fallback, public REST user links, post embeds and absolute media embeds use the same generated path. Actual comment websites and editorial numeric user filters retain their existing semantics.

JSON archives continue assigning imported content to the importing destination administrator. Generated dynamic author links use that destination's actual ID/nicename and retained or replaced permalink settings. No source accounts/credentials are imported. Existing unrelated destination template overrides retain their hierarchy priority; imported generic author templates become the fallback when more specific overrides are absent.

This bounded package does not implement author_name public query compatibility, numeric canonical redirects, author feeds, author_base settings, nicename editing, imported accounts, or global WordPress status/query parity. It has no schema migration.
