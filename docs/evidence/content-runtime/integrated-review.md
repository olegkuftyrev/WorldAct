# Immutable runtime content compiler and startup guards

WorldAct now has a pure compiler for trusted JSON content definitions and an immutable bootstrap value. It records stable owner/revision identities, ordered content and taxonomy keys, detached metadata, explicit visibility/search/routing flags, finite capability-family policy data and a canonical versioned SHA256 profile fingerprint. The existing closed builtin registry remains unchanged. The default bootstrap contains only post/page/category/tag; early guards run before migration reads or client acquisition and before the API app/listener/workers start. Static imports still initialize existing lazy pools and routers. Separate CLI/API processes construct the same static profile rather than share JavaScript object identity.

Custom definitions remain intentionally unwired. Book/genre data may compile in SOURCE tests, but the storage guard rejects custom snapshots. Policy descriptors, metadata and compiler provenance confer no service authority. There is no custom persistence, CRUD, discovery, routing, DDL, loader, retirement or React UI change in this release. Numeric registration-order arrays are preserved even though JavaScript record enumeration sorts integer-like keys. The private provenance brand is an internal construction check, not a sandbox for trusted Node code.
