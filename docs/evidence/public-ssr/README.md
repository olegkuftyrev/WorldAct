# Public SSR frontend author evidence

This is author evidence from an isolated production build, not the independent release verdict. The public renderer keeps the extracted Classic presentation and the source-theme HTML island. The browser consumes the initial model once, validates the current request/account before revealing every JavaScript-enabled public root, and hydrates the existing nodes when the fresh model agrees. Anonymous first paint also waits for that validation. No-JavaScript public HTML remains the server's actual request-time view. Standalone login/admin/editor documents remain the existing JavaScript application shell.

The local forwarding proxy buffered only actual responses from the owned compiled Node server; it did not synthesize successful HTML/models/mutations. Ordinary page interaction used agent-browser, including keyboard and saved credentials passed via stdin.
