# Immutable builtin content registry

The existing post/page/category/tag metadata now comes from one import-free, synchronous registry compiler. It copies trusted JSON data and recursively freezes detached projections, preserving explicit false values, missing features, ordering and builtin identities. It rejects accessors, non-JSON/custom objects, cycles, sparse arrays, malformed adapters, duplicate family keys, REST namespace/base collisions, reserved collections and inconsistent reciprocal associations. Tag retains its `post_tag` REST name and `tags` base.

The six-file runtime extraction moves two metadata values, replaces eight existing enum arguments with identical closed tuples and replaces one post/page membership check with a strict noncoercing predicate. The four existing metadata GET bodies, compatibility adapter literals, protected block/navigation responses, authorization, SQL, title rendering and query behavior remain unchanged. Metadata and supports flags confer no authority. No custom type, taxonomy, loader, capability expansion, schema migration, UI change or arbitrary definition registration is implemented by this foundation.
