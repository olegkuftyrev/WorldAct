# Explicit search Query Title formatting

An explicit `core/query-title` search heading with an existing nonempty final `query.search` now renders `Search results for: “term”`. Omitted `showSearchTerm` means true; valid false renders `Search results`. Search ignores `showPrefix`. The existing source-derived HTML401/numeric term escape walker handles entities without double escaping. The complete UTF-8 wrapper, prefix and quotation markup are reserved before term emission; ordinary rendering remains the sole output charge.

The branch follows unchanged date-query validation and missing-type guards. It preserves h1–h6 wrappers, generic escaping, sanitization, hidden search inputs, query normalization, SQL, authorization, public DTOs and the installed editor UI. Full public documents retain `s` normalization; a renderer preview supplied only raw URL `s` keeps its existing Blog fallback. This change does not implement global search conditional or post-type eligibility, level0 paragraphs, arbitrary raw falsy attributes or a new query alias.
